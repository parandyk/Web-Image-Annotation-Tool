# Image Annotation Tool (Web React)

React web rewrite of the https://github.com/parandyk/Image-Annotation-Tool Avalonia app.

## Getting started

```bash
cd /Web-Image-Annotation-Tool
npm install
npm run dev
```

Build:

```bash
npm run build
```
